## Product Overview

A persistent project-memory layer for AI coding agents, automated end-to-end — set up once,
maintained by agents from then on.

## Users

Developers using Claude Code, primarily — full automation via the bundled plugin. Cursor, Codex,
Gemini CLI, and opencode are supported via pointer files (`AGENTS.md`/`GEMINI.md`/`.cursor/rules`)
that tell those tools' agents to run the CLI manually at session boundaries.

## Value Proposition

Eliminates repeated onboarding and context loss between agent sessions, with no manual
maintenance and no mutation of any project's own Claude Code configuration.
